# Codebase Surgeon

An AI-powered software engineering agent that analyzes GitHub repositories,
finds bugs, proposes and applies fixes, runs tests, and creates pull requests.

## 🚧 Status

Currently under development.

## Tech Stack

- Python
- FastAPI
- Claude API
- Tree-sitter
- Qdrant
- PostgreSQL
- Docker
- GitHub API
- Next.js
- TypeScript

## Planned Features

- Repository analysis
- AST-based code understanding
- Dependency graph generation
- Semantic code search
- AI-powered bug diagnosis
- Automated code modifications
- Docker-based testing
- Regression detection
- Automatic GitHub pull requests
